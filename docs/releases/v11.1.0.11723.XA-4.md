# WPS Office 11.1.0.11723.XA 精简中文版 RPM r4

基于官方 Linux 国际版 RPM，保留文字、表格和演示，补充简体中文资源及六种符号字体，清理已知云端、推广和更新器组件。

## 核心亮点：本项目新增的 QM 兼容转换

**解决“启动页中文，进入文档后工具栏仍是英文”，而不只是把中文语言包复制进去。**

本项目新增跨版本 QM 兼容转换器，为官方中文资源补充国际版 Qt 能识别的翻译索引，处理上下文、哈希冲突和多行按钮。这一转换器及配套的真实 Qt 查询测试不是继承的上游功能。

验证同时覆盖 WPS 自带 Qt 的实际查询，以及文字、表格、演示三个编辑器的主要中文工具栏。整个过程不修改 WPS 程序二进制。中文译文主要来自官方语言包，本项目新增的是兼容转换及验证机制。

## 本版内容

- 修复启动页中文、实际编辑器工具栏仍为英文的问题；三个组件的主要工具栏及多行按钮均经过兼容处理。
- 保留官方原始翻译消息，为国际版自带 Qt 添加可查找的兼容索引，不修改 WPS 程序二进制。
- 启动时设置 WPS 中文界面，首次修改已有语言配置时保存备份。
- 包含 Symbol、Wingdings、Wingdings 2、Wingdings 3、Webdings、MT Extra 六种实际符号字体。
- 不再安装独立 WPS PDF 程序及桌面入口；保留文档导出 PDF 相关共享库。
- 统一标准 Office 菜单分类，提供 `wps`、`wpset`、`wpswpp` 命令和 Fcitx5 / XWayland 兼容处理。

## 下载安装

下载本页的 RPM 和 `SHA256SUMS` 到同一目录。保存文档并退出所有 WPS 窗口后执行：

```bash
sha256sum -c SHA256SUMS
sudo dnf install ./wps-office-11.1.0.11723.XA-4.linuxwps.fc44.x86_64.rpm
```
