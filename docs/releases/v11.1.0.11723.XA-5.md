# WPS Office 11.1.0.11723.XA 精简中文版 RPM r5

基于官方 Linux 国际版 RPM，保留文字、表格和演示，补充简体中文资源、六种符号字体，并随包内置兼容版 FreeType 彻底根除高版本系统下的字体加粗（伪粗体 Fakebold）变黑斑失真问题。

## 本版核心修复

- **彻底修复粗体/伪粗体（Fakebold）显示异常**：
  - 针对系统高版本 FreeType（>= 2.13.0，Fedora 40+ 默认搭载 2.13/2.14）重构了 `FT_GlyphSlot_Embolden` 权重算法导致 WPS 中文字体加粗变成一团黑、模糊失真的问题；
  - 随包内置兼容版 FreeType 2.12.1（来自 Debian 12 维护版 `libfreetype.so.6.18.3`），安装于 `/opt/kingsoft/wps-office/office6/` 自包含目录；
  - 启动脚本自动设置 `LD_PRELOAD` 优先加载内置兼容库，确保 WPS 文字、表格、演示及核心库（`libkso.so`、`libqxcb.so`）正常渲染粗体，完全不影响系统全局 FreeType 及其安全更新。

## 已有特性继承

- 跨版本 QM 兼容转换器，解决国际版编辑器工具栏英文问题。
- 启动时自动设置 WPS 中文界面，首次修改已有语言配置时保存备份。
- 包含 Symbol、Wingdings、Wingdings 2、Wingdings 3、Webdings、MT Extra 六种实际符号字体。
- 不再安装独立 WPS PDF 程序及桌面入口；保留文档导出 PDF 相关共享库。
- 统一标准 Office 菜单分类，提供 `wps`、`wpset`、`wpswpp` 命令和 Fcitx5 / XWayland 兼容处理。

## 下载安装

下载本页的 RPM 和 `SHA256SUMS` 到同一目录。保存文档并退出所有 WPS 窗口后执行：

```bash
sha256sum -c SHA256SUMS
sudo dnf install ./wps-office-11.1.0.11723.XA-5.linuxwps.fc44.x86_64.rpm
```

若已安装旧版，执行升级即可：
```bash
sudo dnf upgrade ./wps-office-11.1.0.11723.XA-5.linuxwps.fc44.x86_64.rpm
```
